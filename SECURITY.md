# Security and private reports

Do not put passwords, tokens, customer records, private URLs or payment details in GitHub issues.

Report a suspected vulnerability privately to **gerrit@3agenteers.com**. Include a minimal description and a redacted reproduction. Do not access another studio, change real records, send customer messages or trigger payments to prove a report.

This repository contains public setup material for an independent hosted service, not its server implementation. The service's privacy information and contact details are at https://kenko-mcp.com/docs/datenschutz/ and https://kenko-mcp.com/nutzungsbedingungen/.
